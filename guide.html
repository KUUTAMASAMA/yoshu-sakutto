使い方ガイド

予習サクッと の使い方

ChatGPTに調べものを任せて、予習を1日30分にするアプリです。
5分で読めます。わからなくなったら、いつでもここに戻ってきてね。

アプリを開く ▶ 使ってみた例（英語・数学・現代文・古文）を見る
① 最初の準備 ② 毎日の予習 ③ 合言葉と便利ワザ ④ クイズとまとめ ⑤ 記録と報告 ⑥ 困ったとき ⑦ ルール

使う場面は3つだけ

🏠
家で・1教科10分
教科書をChatGPTに送って、下調べしてもらう
🚃
電車で・5分
単語クイズで覚える
⏰
授業前・5分
まとめを見返す

1最初の準備（1回だけ）

  1. おうちの人にOKをもらう

    「勉強にAI（ChatGPT）を使いたい」と伝えよう。18歳未満は保護者のOKが必要です。

  2. ChatGPT にログインしておく

    無料のままでOK。有料プランをすすめられても選ばなくて大丈夫。

  3. ChatGPTにプロジェクト「予習」を作る

    ChatGPTの左上のメニュー → 「プロジェクト」の「新しいプロジェクト」→ 名前に「予習」と入れて作成。

    プロジェクトは「予習専用の部屋」。この部屋の中のチャットは、次に覚えさせるルールを毎回守ってくれるよ。

  4. 「予習のルール」を覚えさせる

    下のボタンでルールをコピー → プロジェクト「予習」を開く → 右上の「…」→ プロジェクトの設定 →「指示」の欄に貼って保存。

    ルールの中身を見る 
    
        
    
        
    ボタンの名前が少しちがうこともあるよ。どうしても見つからなければ、アプリの予習画面にある「プロジェクトを作っていないときは」のお願い文を使えばOK。
    
      
    5. 
      
  5. 
        
    このアプリをホーム画面に置く
    
        
    Safari でアプリを開く →下の「共有」ボタン（□に↑のマーク）→「ホーム画面に追加」→「追加」。
    
        
    置いたあとは、いつもホーム画面のアイコンから開くこと。Safariから開くのとは記録が別々になっちゃうよ。ホーム画面から開くと、記録も消えにくくなる。
    
      
    6. 
      
  6. 
        
    アプリの「もう準備できた」を押す
    
        
    予習画面の上に出ている「はじめに」のお知らせが消えるよ。
    
      
    7. 
    

  


  
  
2毎日の予習（1教科10分）

  

    
    
      
  1. 
        
    「📷予習」で教科を押す
    
        
    押した瞬間にタイマーがスタート。
    
        
    
          
    英語数学現代文古文・漢文
    
        
    
      
    2. 
      
  2. 
        
    英語だけ：カメラで英文をコピーする
    
        
    iPhoneのカメラを教科書の英文に向ける → 右下の文字読み取りマーク（枠の中に線）→「すべてを選択」→「コピー」。
    
        
    無料版のChatGPTは、写真を送れる回数が1日数回まで。英語は文字で送って、写真は数学や国語のために取っておこう。
    
      
    3. 
      
  3. 
        
    ChatGPTを開いて、プロジェクト「予習」で新しいチャット
    
        
    アプリの「ChatGPT を開く」を押す → 左上のメニュー → 「予習」→ 新しいチャット。
    
        
    ChatGPT を開く
    
        
    必ず「予習」の中で始めること。外で始めるとルールが効かないよ。
    
      
    4. 
      
  4. 
        
    教科名を打って送る
    
        
    英語：「英語」と打って改行 → 長押しして「ペースト」→ 送信
    ほかの教科：「数学」などと打つ →「＋」→「カメラ」で明日やるページを撮る → 送信
    
        
    
          
    英語
    Many students take part in volunteer activities…
    
        
    
      
    5. 
      
  5. 
        
    ヒントを見て、自分で考える
    
        
    ChatGPTは最初、答えではなくヒントを出すよ。自分で考えてから「答え合わせ」と送ろう（合言葉は次の③で）。
    
        
    
          
    1文目のヒント
    主語は "Many students"。動詞を探してみよう。
    
          
    答え合わせ
    
        
    
      
    6. 
      
  6. 
        
    最初の返事をアプリに貼る
    
        
    最初の返事の最後に【まとめ】と【カード】が出てくる。返事の下のコピーボタン（四角が2つ重なったマーク）→ アプリに戻って貼りつけ →「カードとまとめを保存」。
    
        
    カードとまとめを保存
          
    保存したよ！ 新しいカード 8枚／まとめ 1件
    
        
    
      
    7. 
      
  7. 
        
    「記録する」を押して終わり
    
        
    かかった時間は自動で入る。ずれていたら直してから押してね。
    
      
    8. 
    

    
ChatGPTに行ってもどってきても、アプリは予習中の画面のまま待ってくれているよ。

  


  
  
3合言葉と便利ワザ

  

    
「予習のルール」に書いてあるので、これを送るだけでChatGPTが動いてくれるよ。

    

      
送る言葉こうなる

      
次次のヒントが出る（数学で使う）

      
答え合わせ全文の訳・解き方・質問の答えが出る

      
降参最初からていねいに説明してくれる（「問題がわからない」のとき）

    

    
先に自分で考えてから「答え合わせ」。いきなり答えを見ると、授業で当てられたときに困るのは自分だよ。

  


  

    
予習以外のお願い文

    
「📷予習」の下の「こんなときは」から使えるよ。

    

      
問題がわからない答えは教えず、ヒントを1つずつ出してもらう

      
先生役モード週末に、習ったことをChatGPTに説明する。まちがいを見つけてもらえる。人に説明すると一番覚えるよ

      
中学の内容あやふやな中学の内容を3行で教えてもらって、確認問題を解く

    

    
これも、プロジェクト「予習」の中の新しいチャットで使ってね。

  


  

    
ChatGPTの便利ワザ

    

      
声で話す入力欄の右にある音声のボタンで、しゃべって送れる。先生役モードは、声で説明するとラク

      
読み上げ返事を長押しすると、声で読み上げてもらえる。英文の読み方を聞きたいときに

      
もっとかんたんに説明がむずかしいときは「もっとかんたんに」と送ればOK

    

  


  
  
4クイズとまとめ

  

    🃏 クイズ・電車で5分
    
    
      
  1. 教科を選んで「10問スタート」
    2. 
      
  2. 頭の中で答えてから「答えを見る」
    3. 
      
  3. 
        
    「覚えた ○」か「まだ ×」を押す
    
        
    ×のカードは次回また出る。正直に押すほど早く覚えられるよ。
    
      
    4. 
    

  

  

    📝 まとめ・授業前に5分
    
その日の予習のポイントが3つずつ並んでいるよ。授業の前にさっと見るだけで、当てられても落ち着いて答えられる。

  


  
  
5記録と報告

  

    
「📊記録」では、連続で予習した日数と毎日の予習時間のグラフが見られるよ。点線が目標の30分。

    
週に1回、「LINEで報告する」を押して、相談している人に送ってね。うまくいかないところがあれば、アプリを直していくよ。

  


  
  
6困ったとき

  

    ChatGPTがいきなり答えを出す／ルールを守らない
    

      
プロジェクト「予習」の外でチャットを始めているかも。左上のメニューから「予習」を開いて、その中で新しいチャットを始めてね。

      
それでもダメなら「ルールどおり、ヒントからにして」と送ってみて。

    

  

  

    貼ったのに「カードとまとめが見つからなかった」と出る
    

      
ChatGPTが決まった形で答えなかったのが原因。ChatGPTに
「【まとめ】と【カード】の形で出して」
と送ってから、その返事をもう一度貼ってね。

    

  

  

    写真が送れない／「上限」と出た
    

      
無料版は、写真を送れる回数が1日数回までと決まっているよ。時間がたつとまた送れるようになる。

      
そのあいだは、カメラの文字読み取りで教科書の文字をコピーして、文字で送ればOK（英語と同じやり方）。数式が多い数学は、写真のほうが正確だよ。

    

  

  

    カメラに文字読み取りマークが出ない
    

      
教科書に少し近づけて、文字がはっきり写るようにしてみて。それでも出ないときは、写真アプリで撮った写真を開いて、文字を長押ししてもコピーできるよ。

    

  

  

    ChatGPTのアプリじゃなくて、Safariが開く
    

      
そのままSafariでログインして使ってもOK。アプリで使いたいときは、自分でChatGPTのアプリを開けばOK。

    

  

  

    予習の途中でやめたい
    

      
予習中の画面のいちばん下にある「やめる（記録しない）」を押してね。途中までやったなら、「記録する」で残してもOK。

    

  

  

    記録が消えた／機種変更したい
    

      
記録はこのスマホの中だけに保存されているよ。Safariの履歴やデータを消すと、一緒に消えることがある。

      
機種変更の前は「📊記録」→「書き出し」でファイルを保存して、新しいスマホで「読み込み」してね。

    

  

  

    おかしなカードが入った／まとめを消したい
    

      
カードは「🃏クイズ」→「カードの一覧を見る」→「消す」。まとめは「📝まとめ」の各まとめの「消す」で消せるよ。

    

  


  
  
7守ってほしい3つのルール

  

    
    
      
  1. 答えを丸写ししない。まずヒント、答え合わせは最後。
    2. 
      
  2. ChatGPTもまちがえる。おかしいと思ったら教科書や先生を信じる。
    3. 
      
  3. 個人情報は送らない。名前・住所・学校名・顔が写った写真などはChatGPTに送らない。
    4. 
    

  


  アプリを開く
